# FTG-Overlay（格斗小抄）

> 状态：**需求已确认，demo 已交付**（2026-09-28，含独立管理器窗口）
>
> 一个 Windows 桌面工具：把你记录的格斗游戏连段**自动转换**为直观的图形记法（方向箭头 + 彩色按钮块），在**黑色半透明置顶面板**上**一行一条**显示，练连段时随时可看。附带一个**独立管理器窗口**：按流程「选游戏 → 选角色 → 输入连招 → 选表现形式 → 打开悬浮窗」管理你的连段库。

## 立即体验（demo）

1. 双击 **`FTG-Overlay-demo.exe`**（零依赖，无需安装）——管理器窗口和悬浮窗同时打开；
2. 在管理器「**导入**」页：选游戏、选角色，粘贴连段信息（DreamCancel / 数字记法均可，实时预览），点「保存连招」并勾选「显示」；
3. 在管理器「**展示**」页：调整悬浮窗的主题 / 透明度 / 大小 / 锁定，点「打开悬浮窗」；
4. 想直接改数据：用记事本编辑 **`data\combos.json`**，点「重载数据文件」；标题留空会自动命名为 Combo x；
5. **全局热键只有 `Ctrl+Alt+Q`**（退出程序）——其余一切调整都在管理器里完成，打字时不会再被误触发；
6. **锁定/移动**：悬浮窗右侧有一枚小锁头图标——锁定时鼠标穿透不可移动，点击它（任何状态下都可点）解锁后即可拖动面板；管理器「展示」页也有同样的开关；
7. **管理窗口与悬浮窗关联**：关闭管理窗口即退出整个程序（悬浮窗随之关闭）；
8. 默认鼠标穿透：不影响游戏操作；在游戏里请使用**无边框全屏**或窗口模式（独占全屏下悬浮窗会被画面覆盖）。

连段示例（DreamCancel 写法，悬浮窗自动转图形）：`cr.B, cr.A, df+D(1), qcf+D, rdp+D`
也支持数字记法（`2B, 2A, 26D, 421D`），两种写法可混排；识别不了的记号会原样显示并标黄。

修改源码后重新编译：运行 `src-demo\build.bat`（使用 Windows 自带编译器，无需安装任何东西）。

## 目录结构

```
FTG-Overlay/
├─ FTG-Overlay-demo.exe   # demo 主程序（双击即用：管理器 + 悬浮窗）
├─ data/combos.json       # 你的连段库（记事本可编辑）
├─ data/settings.json     # 界面与悬浮窗设置（自动生成）
├─ src-demo/              # demo 源码（C#/WPF）+ build.bat
├─ docs/                  # 需求、计划、调研、设计稿
```
