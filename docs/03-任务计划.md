## M0 技术验证（Spike）

**目标**：用最小代码验证三个技术前提，避免在错误地基上盖楼。（demo 实现栈为 C#/WPF，原因与正式版栈选择见《需求文档》第 8 节）

任务：

1. 搭 Tauri 2 骨架，实现一个"假小抄"悬浮窗：置顶、半透明、可拖动、鼠标穿透可切换；
2. 全局热键显示 / 隐藏；托盘菜单（退出 / 切换模式）；
3. **在 KOF XIII / 2002 UM 上实测**：无边框全屏上方稳定可见、窗口模式可见；穿透模式下搓招不受影响；记录独占全屏行为（备查）；
4. 采样空闲 CPU / 内存，对照 NFR-01。

**产出 / 验收**：demo 在你的电脑上跑通上述全部行为；你对"看得见、不碍事"点头。

**执行记录（2026-09-28，已完成）**：

- demo 以 **C# / WPF** 实现（本机无 Node/Rust；用系统自带 csc 编译，零依赖，产物约 26KB 单文件 `FTG-Overlay-demo.exe`，符合"解压即运行"）；
- 已实现并验证：置顶、鼠标穿透（`WS_EX_TRANSPARENT`，`M` 键切换拖动模式）、全局热键 9 个（H/T/M/F6–F9/R/Ctrl+Alt+Q）、黑底半透明面板（F6/F7 调透明度、F8/F9 调大小、位置记忆）、两套配色（A 深色默认 / C 霓虹，T 键切换）；
- 记法解析引擎：DreamCancel 写法 + 数字记法混排、`(N)` 目押帧标注、`xx` / `>` 连接符、姿态前缀转箭头（cr.→↓、j.→↑）、按钮名映射（A/B/C/D→LP/LK/HP/HK）、未知记号原样标黄；**自测 19 项全部通过**（`FTG-Overlay-demo.exe --selftest`）；
- 渲染验证：4 条演示连段（含数字写法与容错样例）一行一条正确渲染，截图存于 `docs/design/demo-overlay-screenshot.png`；
- **待你验收**：在 KOF XIII / 2002 UM 无边框全屏（及窗口模式）下实测可见性与穿透手感。

## M1 MVP（可日常使用）

**目标**：你能在 KOF XIII / 2002 UM 的日常练习中真正用上它。

任务：

1. 管理窗口：游戏 / 角色分组树 + 连段列表 + 表单编辑（含记法文本框与实时预览）；
2. JSON 存储层：原子写入 + 备份轮换；**便携布局**（数据目录位于程序目录内）；
3. 悬浮小抄窗：**黑底面板 + 一行一连段**布局（demo 已交付）；管理窗口（游戏/角色分组、连段增删改查、流程指引、表现形式与样式设置）已按第三轮确认提前交付（demo 内），本阶段按使用反馈打磨；
4. 内置「KOF · DreamCancel」档案 v0：A/B/C/D 键帽、cr./st./cl./j. 姿态、qcf/qcb/dp/rdp/hcf/hcb 指令、`(N)` 帧标注、KOF XIII 术语；另附「通用数字记法」v0；
5. 键位映射（FR-10，已确认降级 P2）：仅预留配置结构，本期不做界面；
6. 全局热键：显示隐藏 / 上一条下一条 / 模式切换；
7. 简体中文界面；主题 A 默认 + C 霓虹切换（demo 已含 T 键切换，本阶段精修霓虹效果）。

**验收标准**：你独立录入 10 条真实 KOF 连段（DreamCancel 写法），在游戏中边看边练；全程无数据丢失；穿透模式下搓招不受影响；空闲资源占用达标。

## M2 记法引擎 v1（本项目核心）

**目标**：记法系统完全数据驱动，两种写法混输无碍，后续表示方式"加档案即接入"。

任务：

1. 定稿记法档案文件格式（别名表 / 指令表 / 按钮集 / 连接符 / 帧标注 / 术语表）；
2. 解析器与渲染器解耦，令牌流（IR）定稿——DreamCancel 记法与数字记法汇入同一 IR；
3. 解析器单元测试：样例连段语料 ≥ 30 条（含两种写法混排、歧义与非法输入）；`(1)` 帧标注语义与 DreamCancel 页面核对；
4. 容错 UI：未知记号透传 + 高亮提示；
5. 《档案编写指南》文档；
6. SF6 档案示例（数字记法 + LP/MP/HP 按钮体系，供你以后玩 SF6 直接用）。

**验收标准**：你用两种写法各录 5 条真实连段，渲染正确即通过；故意输入乱码不崩溃、不丢字。

## M3 打磨与开源发布

**目标**：从"能用"到"好用"，完成开源发布，给功能 B 留好门。

任务：

1. 配色换肤落地（A 默认 / C 霓虹，demo 已含基础版）+ 箭头 / 按钮块渲染精修（对齐 SF3 参考图质感）；
2. 导入 / 导出 JSON；数据版本迁移；
3. 托盘完善、开机自启（可选）、单实例运行；WebView2 检测与安装引导；
4. 功能 B 预留：模块注册机制 + 导航空位（仅架构，无任何功能）；
5. **开源发布**：LICENSE（建议 MIT，待确认）、README（含使用说明与"独占全屏限制"说明）、源码仓库、**便携 zip Release（解压即运行）**。

**验收标准**：解压 zip 即可在干净 Windows 10 机器上运行；你的连段库完整迁移无损；功能 B 确定并入时无需改动现有模块即可接入。

## 测试与验证计划

- **解析器**：单元测试（正确 / 歧义 / 非法输入三组语料）+ 渲染快照测试；
- **悬浮窗**：手动测试清单——在 KOF XIII / 2002 UM 上逐项验证：无边框全屏可见、窗口模式可见、穿透、拖动、DPI 125% / 150%、Alt+Tab、分辨率切换；
- **性能**：空闲 / 渲染时 CPU 与内存采样；连段库 500 条时的界面响应；
- **数据**：断电 / 强杀进程后的文件完整性（原子写入验证）。

## 目录结构（规划）

├─ FTG-Overlay-demo.exe   # demo 主程序（双击即用，零依赖）
